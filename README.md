# 牛来

《牛来》2026 年 8 月 5 日上映。导演信雨萌和编剧孙丽芳是母女，两个人做了五年，没有投资，也没有宣发。上映前放出来的那张水墨海报很好看，进影院看到的三维被网友叫做 4399 画质。

我拿 three.js 和 p5.js 做了个同人游戏。三维归 three.js，所有二维归 p5.js，水墨标题、转场、对话框、手机上的按钮都是它画的。

你操控一头牛。牛会叫，叫的内容是「妈妈」。你也可以换成一只鸟，按住跳跃键它就一直往上飞，飞到十五米飞不动，那是天花板。草地里长着「草」，黄色泡沫方块，六个面都印着那个字，弹幕怎么刷的地里就怎么长。

非官方。零投资，零宣发，这点跟电影一样。

## 跑起来

```bash
cd game && npm install && npm run dev
```

打开 http://localhost:5173 。模型和 CC 授权的音频都在仓库里，clone 下来直接能玩。

打包用 `npm run build`，产物在 `game/dist/`，扔任何静态服务器都能跑。

## 怎么玩

| 键 | 作用 |
|---|---|
| `WASD` / 方向键 | 走 |
| `Shift` | 跑 |
| `空格` | 跳。当云雀时按住不放会一直飞 |
| 鼠标拖拽 / 滚轮 | 转视角 / 拉远拉近 |
| `E` / `Enter` / 点击 | 交谈，推进对话 |
| `1` 到 `4` | 选对话选项 |
| `Q` | 换动物 |
| `V` | 换视角，第三人称 / 肩后 / 第一人称 |
| `T` | 换时辰 |
| `P` | 直立和四足切换 |
| `Z` `X` `C` | 牛来 / 妈妈 / 豹拉 各叫一声 |
| `M` `B` | 静音 / 环境音，环境音默认关着。手机上点左侧「声音」键 |
| `Shift`+`1` 到 `5` | 直接跳章 |

手机上右下角一块是摇杆区，左边竖排六个键管跳、叫、换动物、换视角、换时辰、声音开关，摇杆区以外的地方拖动都是转视角。

摇杆推多远决定走多快。推一半是走，推到底才是跑，推到跑的时候拨片上会亮出一个「跑」字。手机上没有 Shift 键，这是唯一能加速的办法，也就是唯一能过河的办法。

## 五种动物

换的是速度、加速度、起跳力和重力，手感真的不一样。

| | 走 | 跑 | 跳多高 | 跳多远 | |
|---|---|---|---|---|---|
| 牛来 | 4.6 | 8.2 | 2.29 m | 9.4 m | 跳的时候喊「妈妈」 |
| 牛妈 | 4.4 | 7.6 | 2.01 m | 8.1 m | 大个子，起步慢，跳的时候喊「牛来」 |
| 豹拉 | 5.6 | 10.4 | 3.02 m | 13.7 m | 跑得最快，跳得最远 |
| 狗 | 5.2 | 9.2 | 2.29 m | 10.5 m | 起步和刹车最快 |
| 云雀 | 4.8 | 7.4 | 3.85 m | 15.0 m | 重力只有别人一半，而且它会飞 |

第一人称会把自己的模型藏掉，眼睛高度按当前动物算。当一只 0.45 米高的云雀时，草比你高。

牛来和牛妈用的是带 Mixamo 骨架的模型，腿、手臂、脊椎、脖子都是真关节，走路时腿真的在迈、手臂反相摆、屈膝、髋部随步伐起伏，起跳收腿、下落伸腿。这套动作没有一帧是预先做好的，模型本身只带一个 T-Pose，全靠 `engine/rig.js` 按速度、转向、腾空状态现算关节角度。

豹拉、狗、云雀还是静态网格，靠整体的挤压拉伸、转弯侧倾、落地压扁装出动作。云雀那对翅膀其实是整个身子在有节奏地开合，远看还挺像。

## 会跳舞

按 `J` 换下一套，`K` 停；手机上摇杆上方那个「舞」键，键面直接写现在跳的是哪套。

四套：**打篮球**（一手低位拍球一手甩开、交替抬膝，每四拍换一个花样）、**左右摇**（双手举过头顶来回摆）、**抖肩**（手肘夹住身体靠肩膀抖）、**转圈**。

牛来和牛妈有骨架，动作是关节级的；豹拉、狗、云雀掰不动关节，退回整体的蹦跳摇摆，幅度给得很足。一推摇杆、一起跳、一换场景就自动停下来。

节拍是合成器现敲的鼓点，按每套自己的 bpm 走，没配原曲——那是有版权的。

## 那条河

五章都有河，宽度都调到走着跳过不去、跑起来跳得过去的那个区间。

最早掉水里的处理是把人推到最近的岸。测的时候发现只要跳得够远，落在河中间偏对岸那一侧，系统就好心把你送上对岸，白给一次过河。现在会记住你是从哪边下的水，推回原来那一岸。

荒漠那一章的水面只剩 2.1 米，河床照样 5.6 米，快干了。云走到这边就散了，散了的云本来是要落在这儿的。

当鸟的时候可以飞过去。它有翅膀，这个我认。

## 五章

1. 草原 · 站起来。牛妈喊「牛，来」，喊到他站起来，名字是这么得的
2. 梦 · 草丛 · 一截会动的绳子。牛来眼神不好，把蛇看成了绳子
3. 梦 · 林子 · 果子和奶。跟着一颗果子找过去，发现一只装饿讨奶的豹子
4. 梦 · 迁徙 · 狼来了
5. 醒来 · 原来是梦

标题页底下可以直接选章。

文本只写查得到的情节。我最早自己补了不少设定，牛二的爷爷、狼的三个孩子、树的第四十七道年轮，写得挺顺。后来去核对，发现好几处是记岔了。灵蛇那段原片是个笑话，牛来眼神不好把蛇当成绳子，我写成了一位庄重的导师。那一版全删了。查不到的角色，比如那条狗，就只写手感，不给它编设定。

## 关于画质的那个决定

这片子出圈靠的是「海报诈骗」这个说法。上映前只放出一张精致的水墨国风海报，进影院看到的是粗糙的低模三维，落差摆在那儿。

游戏把这个落差当成主动的设计来用。

标题画面是 p5.js 实时画出来的真水墨，宣纸纹理、远山、墨牛、飞白、印章都在。点「开始」那一下，墨被烧穿，底下的低多边形世界露出来。之后每次换场都走墨迹扩散，梦境章节还会让水墨从屏幕四角往回渗。

三维那边刻意保持低面数、硬边、程序化拼接，把那个质感当成美术方向来用。原片被吐槽建模复用、场景重复，这里就顺着来。`P` 键能让牛直立行走，原片里牛群在平地上直立走路是著名吐槽点，做成了一个开关。

玩梗，不刻薄。这片子是两个人五年做出来的。

## 树和山

六个树种：松（层叠的锥）、阔叶（几个球堆的团）、垂柳（扁树冠加下垂的一圈）、白桦（细高、白干、冠小靠上）、灌木（没有主干的矮丛）、枯木（光秃的枝杈）。各章按气候配比例，草原是阔叶为主，林子针叶多，荒漠只剩枯木和耐旱灌木。

山有四种轮廓：圆丘、尖峰、平顶台地、连绵的岭。三圈由近及远，越远越淡，做出空气透视。荒漠那章的山过了雪线染白。

这两样都做了合并绘制。原来每棵树是一个 Group 装三到五个 Mesh，每座山一个 Mesh，散三十棵树两圈山就是上百次 draw call——而它们完全静止，没有理由各占一次。现在每棵树先在本地把零件变换好、烘上顶点色，整片林子合并成一个几何；山也是每圈合一个。五章的 draw call 从 1128 降到 795，少了 29%，林子那章降了 38%，而树和山反而都变多了。

合并有个坑：three 的图元里二十面体是非索引的，锥体柱体是索引的，直接混着合并 `mergeGeometries` 会返回 `null`。所以每块几何都要先统一成「只有 position 的非索引几何」。

## 「草」

贴图是 canvas 现画的，不引外部图片，字体复用 UI 那套本机中文字体探测。用 InstancedMesh，一次 draw call 全画完；上下浮动写在顶点着色器里，相位取自每块自己的 `instanceMatrix` 平移，所以每块节奏都不一样，CPU 每帧零开销。

底色压到 `#cf9f14` 这种偏沉的芥末黄。ACES 色调映射会把亮黄推向白，用参考图那种明黄会直接洗成奶油色。

摆放上有两条硬规则，都是踩过坑才加的。

第一条，丛与丛之间要留间距。最早只避开河，结果随机撒点会自然扎堆，出现互相穿插的方块。现在记下已经摆过的位置，太近就换个地方重试。

第二条，一摞里的方块必须放平。最早每块都带 ±7° 的俯仰，层与层之间还留了 4% 重叠，棱角互相扎进去，看着像在融化。现在摞起来的只转 yaw，做出手垒的错落感，层间严丝合缝地贴着放。单块仍然可以歪着躺，那是被丢在草里的。

荒漠那一章没有草。那是妈妈站住让牛来跑的地方，不该有人在旁边打「草」。

## 昼夜

天一直在走，一整天五分钟，按 `T` 直接跳到下一个时辰。

实现上没有给每个场景写四套配色。场景保留自己的签名色，梦境偏青绿，荒漠夜偏冷蓝，时间只在这之上做调制。梦境的 `moodBlend` 只有 0.42，所以它比别处更不受天色影响，梦本来就该这样。

星星画在天空穹顶的着色器里，用方向本身做哈希种子，所以是钉在天上的，不会跟着相机跑。

## 声音

角色叫声用的是 Wikimedia Commons 上自由许可的动物录音，署名表在 [game/public/voice/README.md](game/public/voice/README.md)。灵蛇和云雀没找到合适素材，继续走 Web Audio 合成。

合成那套的做法，锯齿波当声带，三个带通滤波器当共振峰模拟口腔，基频先扬后抑，尾巴上加颤音，再混一点噪声当气声。改基频就是换一个体型，爸爸 94 Hz，妈妈 124 Hz，牛来 215 Hz。

播放层有两条规则。一条叫 solo，新的一声把上一声掐掉，不然连着跳会叠成一片。另一条是整句播放，先算 20 ms 一格的 RMS 包络找出人声真正的起止，从那里切。按响度峰值往后截 0.6 秒的老做法会把「妈妈」的第二个字砍掉，听起来像在叫「妈」。

另外还有脚步、起跳、落地、落水、捡羽毛、对话打字机的点声，以及风和水两条环境床。风每个场景强度不同，水靠近小河才渐渐起来。

蛇的嘶声调了很久都几乎听不见，查下去发现所谓的粉噪声其实是个 140 Hz 的一阶低通，峰值只有 0.016。换成 Kellett 粉噪声之后才正常。

## 打包成小红书小工具

小工具是离线 H5，一套网页打成 zip，由容器 WebView 加载。容器禁掉了 `fetch`、`XHR`、`Worker`、`WebAssembly`、`eval`，只认 html/css/js/img/font/json 几种文件类型，包不能超过 10 MB。

所以这一版做了几件事。模型量化后 base64 内嵌进 JS，位置 f32 转 i16，UV 转 u16，颜色转 u8。语音同样内嵌，用 `decodeAudioData` 解，这个 API 没被禁。p5 换成自写的垫片 `minitool/p5shim.js`，p5 自带的 fetch 和 WebAssembly 都是死代码，但扫描清单照样命中，而且它自己就占一半体积。最后用 `__MINITOOL__` 这个编译期常量把所有联网路径摇掉。

```bash
node tools/bake-minitool-models.mjs game/minitool/models.js
node tools/bake-minitool-audio.mjs                    # 从项目根目录跑，路径是根相对的
cd game && npx vite build --config vite.minitool.config.js
cd dist-minitool && zip -r ../../niulai-minitool.zip index.html assets
```

成品 1.53 MB，禁用 API 扫描零命中。

这条路上摔得最狠的一次是垫片的 `pixelDensity()`。它先改密度再读 `this.width`，而 `width` 的 getter 是 `canvas.width / _density`，于是画布的 CSS 尺寸被砍掉一半。画面被拉伸盖满屏幕，看起来一切正常，但界面画在 187×406 的坐标系里，手指报的是 375×812 的坐标，差整整一倍。手机上按钮点不中、摇杆推不动，就是这么来的。网页版用的是真 p5，所以在浏览器里怎么试都是好的。
