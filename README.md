# 牛来 · 梦醒之前

同人游戏。致敬 2026 年 8 月 5 日上映的国产动画电影《牛来》。

three.js 管三维，p5.js 管所有二维（水墨、转场、对话框、按钮）。跑在浏览器里，也能打包成小红书小工具。

**非官方。零投资。零宣发。和电影一样。**

---

## 这是啥

一个第三人称探索 + 对话游戏。你操控一头牛。牛会叫。叫的内容是「妈妈」。

你也可以选择不当牛，去当一只鸟。鸟会飞。按住不放会一直飞。飞到 15 米就飞不动了，这是天花板，物理意义上的。

草地里长着「草」。是那个「草」。黄色泡沫方块，六个面都是。弹幕怎么刷的，地里就怎么长。

cd game && npm install && npm run dev

## 五种动物，手感真的不一样

不是换皮。改的是速度、加速度、起跳力、重力。

| | 走 | 跑 | 跳高 (m) | 跳远 (m) | 备注 |
|---|---|---|---|---|---|
| 牛来 | 4.6 | 8.2 | 2.29 | 9.4 | 标准。跳的时候喊「妈妈」 |
| 牛妈 | 4.4 | 7.6 | 2.01 | 8.1 | 大个子，起步慢，跳的时候喊「牛来」 |
| 豹拉 | 5.6 | 10.4 | 3.02 | 13.7 | 跑最快跳最远 |
| 狗 | 5.2 | 9.2 | 2.29 | 10.5 | 起步和刹车最快 |
| 云雀 | 4.8 | 7.4 | 3.85 | 15.0 | 重力只有别人一半。**而且它会飞** |

第一人称会把自己的模型藏掉，眼高按当前动物算——当一只 0.45 米高的云雀时，草比你高。

模型是同一批静态网格，一根骨头都没有。所有动作——呼吸、走路的挤压拉伸、转弯侧倾、落地压扁、
说话点头、扑翼——都是每帧现算出来的形变。云雀的「翅膀」其实是整个身子在有节奏地开合。

## 那条河

五章都有河。**走着跳过不去，得先跑起来。**

| 场景 | 水面宽 | 地面缺口 |
|---|---|---|
| 草原 | 4.3 | 5.6 |
| 梦·草丛 | 4.3 | 5.6 |
| 梦·林子 | 4.0 | 5.3 |
| 梦·荒漠 | 2.1 | 5.6 |
| 醒来 | 4.3 | 5.6 |

荒漠那条水面只剩 2.1 米，河床照样 5.6 ——快干了。

掉水里会被推回**出发那一岸**，不是最近那一岸。不然你落在河中间偏对岸的地方，就等于白嫖过河了。

当鸟的时候可以直接飞过去。这不算作弊，这是生物学。

## 昼夜

天一直在走，一整天 5 分钟。按 `T` 跳时辰。

不是给每个场景写四套配色。**场景保留自己的签名色**（梦境偏青绿、荒漠夜偏冷蓝），
时间在那之上做调制。梦境的 `moodBlend` 只有 0.42，所以它比别处更不受天色影响——梦本来就该这样。

星星画在天空穹顶的着色器里，用方向本身做哈希种子，钉在天上，不跟着相机跑。

## 美术上那个决定

《牛来》最出名的不是剧情，是「海报诈骗」——上映前只放一张精致的水墨国风海报，
进影院看到的是被网友称作「4399 画质」的粗糙三维。

游戏把这个落差**变成了主动的设计**：

- 标题画面是 p5.js 实时画的真水墨（宣纸纹理、远山、墨牛、飞白、印章），点「开始」的瞬间被墨烧穿，露出底下的低多边形世界。
- 之后每次换场都用墨迹扩散，梦境章节还会让水墨从四角往回渗。
- 3D 刻意保持低面数、硬边、程序化拼接。把那个质感当美术方向，不当事故。
- 原片被吐槽建模复用、场景重复。这里就顺着来。
- `P` 键能让牛直立行走——原片里牛群在平地上直立行走是著名吐槽点，做成了开关。

这片子是导演信雨萌和编剧孙丽芳两个人、五年、零投资做出来的。玩梗，不刻薄。

## 「草」

贴图是 canvas 现画的，不引外部图片。用 InstancedMesh，一次 draw call；
上下浮动写在顶点着色器里，相位取自每块自己的 `instanceMatrix` 平移，所以节奏各不相同，CPU 每帧零开销。

底色压到 `#cf9f14` 这种偏沉的芥末黄——ACES 色调映射会把亮黄推向白，用参考图那种明黄会直接洗成奶油色。

两条硬规则，都是踩过才加的：

- **丛与丛之间留间距。** 随机撒点会自然扎堆，出现互相穿插的方块。
- **一摞里的方块必须放平。** 最初每块带 ±7° 俯仰、层间还留 4% 重叠，棱角互相扎进去，看着像在融化。

**荒漠那一章没有。** 那是妈妈站住让牛来跑的地方，不该有人在旁边打「草」。

## 声音

角色叫声用 **Wikimedia Commons 的自由许可动物录音**，署名见
[game/public/voice/README.md](game/public/voice/README.md)。没有合适素材的角色（灵蛇、云雀）走 Web Audio 合成。

合成那套的做法：锯齿波当声带，三个带通滤波器当共振峰（模拟口腔），基频先扬后抑，
尾巴加颤音，混一点噪声当气声。改基频就是换一个体型——爸爸 94 Hz，妈妈 124 Hz，牛来 215 Hz。

播放层有两条规则：**solo**（新的一声掐掉上一声，不然连跳会叠成一片）和
**整句播放**（先算 20 ms 一格的 RMS 包络，找出人声真正的起止，从那里切——
按响度峰值截 0.6 秒会把「妈妈」的第二个字砍掉）。

## 打包成小红书小工具

小工具 = 离线 H5。一套网页打成 zip，容器 WebView 加载。容器禁掉了 `fetch`/`XHR`/`Worker`/`WebAssembly`/`eval`，
只认 html/css/js/img/font/json 这几种文件类型，包上限 10 MB。

所以这一版：

- 模型量化后 base64 内嵌进 JS（位置 f32→i16、UV→u16、颜色→u8）
- 语音同样内嵌，用 `decodeAudioData` 解——这个 API 没被禁
- p5 换成自写垫片 `minitool/p5shim.js`。p5 自带的 fetch / WebAssembly 都是死代码，但扫描清单照样命中，而且它自己占一半体积
- `__MINITOOL__` 编译期常量把所有联网路径摇掉

```bash
node tools/bake-minitool-models.mjs game/minitool/models.js
node tools/bake-minitool-audio.mjs                              # 从项目根目录跑，路径是根相对的
cd game && npx vite build --config vite.minitool.config.js
cd dist-minitool && zip -r ../../niulai-minitool.zip index.html assets
```

成品 1.53 MB，禁用 API 扫描 0 命中。

## 素材去哪了

**仓库里没有模型和影片音频。** 不是忘了传，是不能传：

| 东西 | 为什么不在 | 怎么补 |
|---|---|---|
| `game/public/*.glb` | 豹拉 / 狗 / 云雀的模型是从 GooFstore **买**的，付费商品，没有再分发授权 | 自己弄四个 glb 放进 `game/public/`，叫 `niulai/baola/dog/bird.glb` |
| `niulai.mp3` `mother.mp3` `baola.mp3` | 从影片提取的台词。配音是导演和编剧本人的声音，**未授权** | 用自己录的，或删掉 `manifest.json` 里对应行回落到合成音 |
| `movie-clips/` | 原片素材 | 不需要 |

CC 授权的那几段动物叫声（牛二 / 爸爸 / 狗 / 狼，以及牛来和妈妈的 CC 备份版）都在仓库里，署名齐全，可以直接用。

换句话说：**代码是完整的，皮是你自己的。**
